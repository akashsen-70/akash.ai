# Akash.ai – Smart AI Study + Chat Assistant

This is a full-stack AI application designed to help students with their studies and provide a conversational AI experience.

## Features

- **Study Mode**: Generate detailed, exam-oriented notes from text or images.
- **Chat Mode**: A general-purpose AI assistant for questions and problem-solving.
- **Multimodal Support**: Upload images for analysis and OCR.
- **Real-time Sync**: Uses Firebase for real-time chat history.
- **Authentication**: Google Login and Guest Mode support.

## Tech Stack

- **Frontend**: React, Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express
- **Database**: Firebase Firestore
- **AI**: Google Gemini API

## Setup

1. Clone the repository.
2. Install dependencies: `npm install`
3. Create a `.env` file and add your `GEMINI_API_KEY`.
4. Set up a Firebase project and add your configuration to `firebase-applet-config.json`.
5. Run the development server: `npm run dev`
